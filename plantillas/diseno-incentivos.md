# Diseño de metas e incentivos

## Antes de lanzar el incentivo, revisa

- [ ] ¿Son máximo 3 metas?
- [ ] ¿Cada meta depende de lo que el empleado controla?
- [ ] ¿Entre 60 % y 80 % del equipo puede lograrla con buen esfuerzo? (Revisa los
      datos de las últimas semanas, no lo que "deberían" poder hacer.)
- [ ] ¿El avance se puede ver cada día?
- [ ] ¿Se paga cada semana o cada quincena, en fecha fija?
- [ ] ¿Tiene niveles en vez de todo o nada?
- [ ] ¿Combina una parte individual y una de equipo?
- [ ] ¿Va encima de un sueldo base justo?
- [ ] ¿Las reglas están escritas y no van a cambiar durante el periodo?
- [ ] ¿Se lo explicaste al equipo y les preguntaste si les parece justo?

## Ejemplo: tienda o restaurante

**Meta de equipo:** ticket promedio por turno.
**Meta individual:** cero faltas y cero retardos en la semana.

| Nivel | Condición | Premio semanal |
|---|---|---|
| Bronce | Asistencia perfecta | $X |
| Plata | Asistencia perfecta + el turno supera el ticket promedio de referencia | $2X |
| Oro | Asistencia perfecta + el turno supera la referencia en 10 % | $3X |

- La referencia es el promedio real de las últimas 4 semanas, no una cifra deseada.
- El avance del turno se escribe en una pizarra al cierre de cada día.
- Se paga cada viernes junto con el sueldo.
- Se revisa con el equipo después de 4 semanas.

## Señales de que hay que ajustar

| Señal | Ajuste |
|---|---|
| Nadie llega ni al primer nivel | La meta es muy alta: bájala al promedio real |
| Todos llegan al nivel más alto fácilmente | Añade un nivel, pero avísalo antes del siguiente periodo, nunca a mitad |
| Se pelean o se roban clientes | Aumenta el peso de la parte de equipo |
| Cumplen la meta pero baja la calidad | Añade una condición de calidad (quejas, devoluciones) |
| Al principio funcionó y luego dejó de importar | Rota la meta cada 2–3 meses o cambia el tipo de premio |
